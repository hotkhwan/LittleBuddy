# Audio manifest — fields, licensing rules, drop-in procedure

**What this covers:** background music. Sound effects are not here — every SFX in this project
is synthesised by `tools/generate_sfx.gd`, so they are ours outright and carry no licence
surface at all; they are recorded in `docs/ASSET_MANIFEST.md` under *Audio*.

Music is different. It is generated by a human in an external tool and arrives as a file with
a provenance story attached, and a story that lives in someone's memory is not provenance. So
it lives as data, in `game/content/audio/manifest.json`, and the loader will not play a track
whose story is incomplete.

| | |
|---|---|
| Manifest | `game/content/audio/manifest.json` |
| Loader + licence gate | `game/scripts/audio/music_manifest.gd` |
| BGM state machine | `game/scripts/audio/bgm_state_machine.gd` |
| Audio manager | `game/scripts/audio/audio_director.gd` |
| Music files (created on first delivery) | `game/audio/music/` |
| Tests | `game/tests/cases/test_audio_music_manifest.gd`, `game/tests/cases/test_audio_director.gd` |
| Creative brief | `docs/MUSIC_BRIEFS_FOR_ANNY.md` |

---

## 1. Current state: there is no music, and that is fine

**No music file exists in this repository.** Both expected tracks are listed in the manifest
*before* they exist, with honest placeholder values, so that a delivery is a file drop rather
than a code change.

The build is therefore **silent-safe**, and that is a tested property rather than a hope:

- `set_state()` succeeds for every state and honestly reports that nothing is playing.
- No engine error, no broken resource path, and **no repeated warning** — a missing file is
  the designed state of this build, not a fault, so nothing complains about it.
- Volume controls and mute work whether or not music exists, so a settings screen does not
  need to know.
- `AudioDirector.is_silent_build()` returns `true` today. When it starts returning `false`,
  music has arrived.

`test_audio_director.gd::_test_a_build_with_no_music_behaves_normally()` drives every state,
every trim and mute through a director with nothing to play. If someone later makes music
mandatory by accident, that case fails.

## 2. Manifest format

```json
{
  "manifestVersion": 1,
  "musicDir": "res://audio/music",
  "tracks": [
    {
      "trackId": "littleDaysTheme",
      "source": "",
      "createdAt": "",
      "downloadedAt": "",
      "licenseEvidence": "PENDING",
      "commercialUse": "pending",
      "localPath": "res://audio/music/little_days_theme.ogg",
      "loopStart": 0.0,
      "loopEnd": 0.0,
      "volumeDb": -12.0,
      "usageScenes": ["menu"]
    }
  ]
}
```

JSON keys are camelCase, per `CLAUDE.md`.

### Every field, and why it is required

| field | type | meaning |
|---|---|---|
| `trackId` | String | Stable camelCase id. The game addresses music by this, never by filename, so a re-export or a container change costs nothing. Must be unique; the **first** entry wins a duplicate, so a later edit cannot quietly override a reviewed row. |
| `source` | String | Where it came from, in enough detail to find it again: tool, account, plan. `"Suno v4, Anny's account, Pro plan"` — not `"Suno"`. |
| `createdAt` | String | `YYYY-MM-DD` the track was generated. Empty until known. |
| `downloadedAt` | String | `YYYY-MM-DD` the file entered this repository. Distinct from `createdAt` because licence terms change: what matters legally is the terms in force when we took the file. Empty until delivered. |
| `licenseEvidence` | String | Path to, or description of, the evidence that we may ship this commercially. `"PENDING"` until it exists. See §3. |
| `commercialUse` | String | `"verified"`, `"pending"` or `"denied"`. **Only the exact string `"verified"` permits playback.** |
| `localPath` | String | `res://` path to the audio file. May point at a file that does not exist yet — that is the normal case. |
| `loopStart` | float | Loop start, seconds. `0.0` means the beginning. |
| `loopEnd` | float | Loop end, seconds. `0.0` means the end of the file, so `0.0`/`0.0` loops the whole thing — what a well-made loop wants. A range that ends before it starts falls back to the whole file rather than producing a zero-length loop that would buzz on a device. |
| `volumeDb` | float | The track's own level, negative. Clamped to a maximum of −6 dB (§4). |
| `usageScenes` | Array[String] | Which BGM states this track plays under: `menu`, `house`, `miniGame`, `reward`. A state with no track is silent, which is legal. |

### Schema strictness

- **A row missing any of the eleven fields is dropped**, with the reason recorded in
  `errors()`. A track with no `licenseEvidence` key is not a track with pending evidence; it
  is a track nobody has thought about.
- **A value out of schema is kept verbatim and reported**, not silently normalised. Rewriting
  `commercialUse: true` to `"pending"` would be tidier and would erase the evidence that
  someone typed something wrong.
- **Unknown fields are preserved** through a load/save round-trip, so a field added by a later
  version of the manifest survives intact.
- **A missing or corrupt manifest yields an empty catalogue and safe defaults**, never an
  engine error — the same contract the save layer has for a corrupt profile.

## 3. Licensing rules

### The gate

A track is played only when **both** hold:

1. `commercialUse` is exactly `"verified"`, and
2. `licenseEvidence` names something real — not `""`, `"PENDING"`, `"pending"`, `"TODO"`,
   `"tbd"`, `"none"`, `"n/a"` or `"unknown"`.

Everything else is refused. Not "logged and played" — refused. `"Verified"`, `"verified?"`,
`"yes"`, a bool `true`, an integer `1`: all refused. **The gate fails closed**, so a typo can
never open it, and `test_audio_music_manifest.gd` asserts each of those cases against a
fixture whose file genuinely exists — so the licence is demonstrably the only thing standing
between the file and playback.

Refusal reasons, in the order they are checked:

| reason | meaning |
|---|---|
| `unknownTrack` | no such `trackId` |
| `commercialUseUnverified` | not exactly `"verified"` |
| `licenceEvidenceMissing` | `"verified"` with nothing behind it |
| `localPathMissing` | `localPath` is empty |
| `fileMissing` | nothing on disk at that path |

The licence is checked **before** the disk deliberately. A refused track must report its
licence problem rather than hiding behind a missing file and quietly becoming playable the day
someone drops a file in.

### Warnings: loud about the right thing

- `fileMissing` → **silent.** It is the designed state of this repository. A boot-time warning
  for the designed state is noise, and noise is how a real warning gets ignored.
- `commercialUseUnverified` / `licenceEvidenceMissing` **and a file is present** → one engine
  warning per track. Someone has dropped a delivery in without recording where it came from,
  and that is the one audio mistake in this project that could reach a shipped build.
- Either way, `AudioDirector` emits `track_unavailable(trackId, reason)` once per track so a
  diagnostics panel can show the truth without anything being logged per frame.

### The rules behind the rules

- **Only tracks with verified commercial-use rights may ever be integrated.** A track marked
  `pending` is fine and costs nothing; the game simply stays silent there, which it already
  does.
- **Never rip audio from YouTube or from any other site, service, game or video.** Not as a
  placeholder, not temporarily. A ripped file in a repository is a shipped file eventually.
- **Do not fabricate or synthesise a "placeholder" music file** and commit it as a real asset.
  Silence is the placeholder. It is a supported configuration and it is tested.
- **Never delete a `denied` row.** A deleted row is indistinguishable from a track nobody
  checked; a `denied` row is a decision on the record.
- Evidence for music goes in `docs/licences/music/<trackId>/` and is referenced from
  `licenseEvidence`. What to capture is in `docs/MUSIC_BRIEFS_FOR_ANNY.md` §4.

## 4. Levels, and why music is capped

`MusicManifest.MAX_VOLUME_DB` is **−6 dB** and nothing can exceed it: not a manifest entry, not
a trim, not a caller.

Music plays *under* the English the child is meant to hear. The loudest SFX in the game sits
at 0 dB of trim over a −6 dBFS file, so holding music 6 dB below that keeps a spoken prompt —
*"Can you say milk?"* — clearly on top of it. The three trims (`master`, `music`, `sfx`) can
only **attenuate**: their maximum is 0 dB, because nothing in this game should ever play louder
than the level its asset was authored at.

The mix, from file to speaker:

```
track volumeDb  +  music trim  +  master trim  →  clamped to [-60 dB, -6 dB]
```

Seeded levels: `littleDaysTheme` at −12 dB (menus, no speech competing), `hungryBunny` at
−16 dB (plays under prompts). Adjusting these after listening on the device is a one-number
manifest change and needs nothing from the composer.

### Transitions are never hard cuts

`bgm_state_machine.gd` gives every transition a crossfade, floored at 0.25 s and typically
0.5–1.5 s. A hard cut is a transient, and a transient is the thing a 4-year-old holding an
iPad 30 cm from their face should never be given — the same reasoning behind the measured
attack ramp on every SFX (`test_audio_assets.gd`). `test_audio_director.gd` asserts that no
state, including an unknown one, can produce a cut.

## 5. Drop-in procedure

When a delivery arrives (files + evidence, per `docs/MUSIC_BRIEFS_FOR_ANNY.md`):

1. **Read the evidence before touching the file.** If the plan terms do not clearly grant
   commercial use of the generation, stop here: leave `commercialUse` as `"pending"` and the
   game stays silent, which costs nothing. Do not "verify it later".

2. **Store the evidence** in `docs/licences/music/<trackId>/` — the generation screenshot, the
   plan/terms capture with its capture date, the account and plan name, the prompt.

3. **Copy the audio file** to `game/audio/music/` (create the directory on the first
   delivery), named exactly as in the brief:
   - `little_days_theme.{wav,mp3,ogg}` → `littleDaysTheme`
   - `hungry_bunny.{wav,mp3,ogg}` → `hungryBunny`

   Any of the three containers works. The loader probes the declared `localPath` first, then
   the same basename with each accepted extension, so a delivery of `.mp3` against a manifest
   that says `.ogg` still plays. No conversion is needed to make it work.

4. **Fill in the manifest row** in `game/content/audio/manifest.json`:
   ```json
   "source": "Suno v4, Anny's account, Pro plan",
   "createdAt": "2026-09-21",
   "downloadedAt": "2026-09-22",
   "licenseEvidence": "docs/licences/music/littleDaysTheme/ (plan terms captured 2026-09-22)",
   "commercialUse": "verified",
   "localPath": "res://audio/music/little_days_theme.mp3",
   ```
   Add `loopStart`/`loopEnd` if the composer gave loop points. Leave `volumeDb` alone for now.

5. **If it is a `.wav`, check the import is lossless.** Godot 4.4+ defaults new WAV imports to
   QOA, which is lossy: set `compress/mode=0`, leave `edit/normalize` off, and let the runtime
   own looping rather than the importer. (`.mp3` and `.ogg` are unaffected.)

6. **Run the suite.**
   ```
   /Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script res://tests/run_tests.gd
   ```
   Two audio cases will now be exercising the *playing* path. Two assertions are written to
   fail deliberately once real music lands — the "this build is silent" checks in
   `test_audio_music_manifest.gd::_test_shipped_manifest_is_silent_today()` and
   `test_audio_director.gd::_test_a_build_with_no_music_behaves_normally()`. **Update them
   together with the licence evidence; do not simply delete them.** They are the record that
   the silent path still works, and the silent path is what a device with a corrupted download
   falls back to.

7. **Listen on the device, not on a laptop.** Play the menu, walk into a room, run the milk
   mission, and check that a spoken prompt still cuts through. If it does not, lower the
   track's `volumeDb` by 2–3 dB and listen again. That is the only knob that should need
   turning.

8. **Record the track** in `docs/ASSET_MANIFEST.md` under *Audio*, alongside the generated
   SFX, so the repository has one place that lists every third-party asset it ships.

## 6. Using the audio manager

`AudioDirector` is a plain `Node`, not a singleton. Instantiate it, compose it into a scene, or
register it as an autoload — all three work, and the tests use the first.

```gdscript
var audio := preload("res://scripts/audio/audio_director.gd").new()
add_child(audio)
audio.bind_sfx_player(get_node_or_null("/root/Sfx"))  # one mixer owns every level

audio.set_state(AudioDirector.STATE_HOUSE)   # menu / house / miniGame / reward / silent
audio.set_state(AudioDirector.STATE_REWARD)  # a celebration interrupts...
audio.return_to_previous_state()             # ...and hands the room back

audio.set_master_volume_db(-6.0)
audio.set_music_volume_db(-3.0)
audio.set_sfx_volume_db(0.0)
audio.set_muted(true)
```

Callers say **where the child is**, never which track to play; the manifest decides what that
sounds like. That indirection is the whole reason music can arrive later without a single
gameplay file changing, so please keep track ids out of gameplay code.

`set_state()` returns `false` when the state has no cleared, present track. That is a normal
answer today and callers must treat it as one — never as an error, and never as a reason to
change what happens on screen.
