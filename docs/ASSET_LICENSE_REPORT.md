# Asset licence report — Little Days Founder Preview

Audit date: 2026-09-19. Covers everything that ships inside the build.

**Verdict: clear for a closed Founder Preview.** Every shipping asset is either
CC0, generated by this project under a commercial licence, or built procedurally
from code in this repository. No item below blocks distribution to invited
families. Two items are flagged for attention before any *public* store release.

---

CC0 is a public-domain dedication: no attribution obligation, no share-alike, and
commercial use is permitted. Each pack's own `License.txt` ships alongside it and
must stay there. We credit Kenney anyway — it costs nothing and it is right.

## 3. Procedural content — no licence to manage

The house, every room, all furniture, the doors, the room signs, the storage,
every kitchen item and every UI shape are **built in code** (`scripts/house/`,
`scripts/kitchen/`, `scripts/ui/`). Nothing was downloaded. This is the majority
of what is on screen.

## 4. Code adapted from open source

| Project | Licence | What we took | Status |
|---|---|---|---|
| `KaganAyten/RestaurantGame3DUnity` | MIT (verified via GitHub API) | **Mechanics only.** Unity/C# → Godot/GDScript; no source copied or transliterated. | ✅ clear |

That repo bundles **DOTween** (Demigiant, own licence — *not* MIT) and
**TextMesh Pro / EmojiOne** (Unity Companion Licence). Its own MIT does not
cover them. **None of them is in this project** — Godot has `Tween` built in.
Full detail in `docs/THIRD_PARTY_NOTICES.md`.

## 5. Fonts

No `.ttf` or `.otf` ships. All text uses Godot's built-in default font, which is
covered by the engine licence. ⚠️ If a custom font is added for "Little Days"
branding, it needs its own licence check — display fonts are a common trap.

## 6. Audio

**There is no audio in the build.** Music is pending from Anny (Suno). The
manifest requires `licenseEvidence` and `commercialUse` per track, and the loader
refuses any track whose commercial use is not verified. See
`docs/AUDIO_MANIFEST.md`.

⚠️ Two hard rules, recorded here because they are easy to break under deadline:
never rip YouTube audio, and Suno's commercial-use rights depend on the
subscription tier **at the time of generation** — save the receipt and the
generation date with each track.

## 7. Engine

Godot 4.7.2, MIT. MoltenVK (Apache 2.0) ships inside the iOS export. Godot's
licence text must appear in the app's third-party notices. ⚠️ **Not yet done** —
required before public release, not for a closed preview.
