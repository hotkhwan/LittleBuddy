# Little Buddy — Asset Manifest

Every third-party asset shipped in the game, with its licence. Companion to
`docs/ASSET_SOURCING_PLAN.md`, which records *why* each source was chosen and the licence
verification method.

**Verification standard:** every licence below was read from the `License.txt`/`LICENSE`
inside the actually-downloaded archive, not from a website summary or from memory. The
licence file ships alongside the assets in this repo.

**Summary: every third-party asset is CC0. Attribution is required for nothing.**

The Food Kit, Cube Pets and Minigolf colormaps have **different md5s** and are not interchangeable.

## Audio

| source | assetName | localPath | license | attributionRequired | commercialUse | modifiedByUs |
|---|---|---|---|---|---|---|
| **Original — ours** | 10 generated SFX | `game/audio/sfx/*.wav` | n/a (we authored it) | no | yes | generated by `tools/generate_sfx.gd` |

Added 2026-09-18: **`place_soft.wav`** (−11.0 dBFS peak, 8.0 ms attack — a stable C5+E5 major
third for a successful drop, deliberately *not* the descending fifth of `drop_return`, so
"landed right" and "slid back home" do not sound alike) and **`room_change.wav`** (−13.0 dBFS,
15.6 ms attack — an unhurried rising fifth, quieter than any reward sound because it happens
constantly). Both synthesised by the same generator; no new licence surface.

**Import format matters here.** Godot 4.4+ defaults new WAV imports to **QOA, which is lossy**,
so the two new files initially imported lossy while the original eight were PCM. An exported
build plays the *imported* sample, so a lossy import would mean the measured peak and attack
numbers are not what the child actually hears. All ten are now `compress/mode=0` and a test
enforces lossless PCM, no import normalisation and no loop.

Deliberately **not** sourced. Every sample is synthesised from sine partials by our own
generator, so there is **zero third-party audio licence surface**. Kenney's CC0 audio packs
were measured and rejected on quality for a small child: several peak at −1.4 dBFS with a
first sample at 0.86 of full scale (an instantaneous DC step, i.e. an audible snap), whereas
ours peak no higher than −6 dBFS and start and end at exactly 0.0000.

## Sources deliberately NOT used

| source | reason |
|---|---|
| **Quaternius** | **No longer CC0.** `https://quaternius.com/license.html` now serves the Quaternius Asset License v1.0 (last updated 2026-08-28). §3(a) forbids redistributing the assets "*as a standalone asset, asset pack, stock file, template, or similar product… regardless of how much the Assets have been modified*", which makes committing raw files to this repo questionable if it ever becomes public. Their own FAQ and pack pages still show a CC0 badge — the site contradicts itself. They also ship **no GLTF/GLB**. A fully CC0 path exists, so this risk is unnecessary. |
| **Sketchfab** | Nothing found that was both unambiguously licensed *and* stylistically fitting. Skipping it removes a class of legal risk. |
| **Poly Pizza (as a primary source)** | Licences are per-model and uploader-declared, and demonstrably inconsistent — the same Tiny Treats pack has models tagged both CC0 and CC-BY on one page. Fine for a one-off if verified against the creator's own page. |
| **Kenney Brick Kit** | Its studded variants are visually LEGO bricks; LEGO has litigated brick trade dress in several jurisdictions. Owner chose procedural blocks instead. |
| **Any CC-BY asset** | Each one adds a perpetual attribution obligation to a shipped children's app. A pure-CC0 set was achievable, so we took it. |

## Pending owner action

**Tiny Treats "Playful Bedroom"** ($7.95, CC0) is the best style match for the nursery and
would replace the retinted Kenney furniture. Because it is **paid**, it needs a human purchase
before it can be fetched. The nursery is built to swap cleanly — see
`docs/NURSERY_SWAP_CONTRACT.md`.

**Correction to earlier research:** this document previously claimed Tiny Treats packs
"cannot be downloaded non-interactively". That is **wrong for the free packs**. itch.io exposes
a scriptable download API, verified end-to-end with plain `curl`, no login, no browser, no
cookies:

```
POST https://tinytreats.itch.io/<pack>/download_url      -> signed page URL
POST https://tinytreats.itch.io/<pack>/file/<file_id>    -> {"url": "<signed CDN URL>"}
GET  <that URL>                                          -> the zip
```

*Bubbly Bathroom* was pulled this way (5,668,736 bytes, valid zip, 84 `.gltf`+`.bin`, one
shared atlas). Its bundled `License.txt` reads verbatim: *"License: (Creative Commons Zero,
CC0) … This content is free to use in personal, educational and commercial projects. Support
me by crediting Isa Lousberg, www.isalousberg.com (this is not mandatory)"* — by Isa Lousberg,
v1.1, 28/10/2025.

It was **deliberately not used**: it covers only towels, toothbrushes and a duck (there is no
bar of soap, only a soap *dish*, which would teach "dish"), and those three objects already
read well as procedural models. Swapping correct procedural art for third-party art is an
art-style decision, not a mis-teach fix, and it would add 5.4 MB, a second atlas, `.gltf`
external-buffer import risk and a new licence surface for no teaching gain. Reproducible with
the commands above whenever wanted.
